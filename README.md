# Repository includes:
MotorPH_Products_Cleaned_2025.csv: Standardized product catalog containing all 50 SKUs with parsed product types, corrected titles, formatted unit prices, and validated manufacturing and acquisition years.

MotorPH_Sales_Cleaned_Q3_2025.csv: Cleaned transaction records for Q3 2025 with corrected product names, standardized payment and client types, validated totals, and ISO-formatted dates

# Data Preprocessing & Analysis Script: 
(motorph_data_preprocessing.py) Python script utilizing pandas for raw data loading, missing value audits, duplicate checks, name correction mappings, data type casting (int64), and output generation.
